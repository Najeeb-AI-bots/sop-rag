# Browse Node Update Policy

**Category code:** BRW-03
**NRR Column R descriptive name:** Browse node update
**Knowledge link GUID:** GDBRWN0DE55NC842

## When this applies
A product is listed under an incorrect browse node (category), causing it to
appear in the wrong search/category results, or to be wrongly suppressed by a
category-level rule.

## Resolution steps
1. Identify the correct browse node for the product type.
2. Guide the seller to update the item's category / browse node mapping.
3. Confirm the product surfaces correctly after reindexing.

## NRR audit guidance
- Column R descriptive name must read exactly: "Browse node update".
- Attach knowledge link GUID GDBRWN0DE55NC842.
- Distinguish from Stranded Inventory: browse-node issues are a
  categorization error, not an offer-activation error.
