# NPT (Non-Productive Time) Coding Policy

**Category code:** NPT-07

## When this applies
Agent time that is not spent on live case handling must be coded to the
correct NPT reason so productivity and capacity reporting stay accurate.

## Common NPT codes
- **Training** — scheduled learning, onboarding, upskilling sessions.
- **Coaching / 1x1** — time in a documented coaching conversation.
- **System downtime** — tooling/platform outage preventing case work.
- **Meeting** — team or business meetings.
- **Break** — scheduled rest breaks.

## Resolution / audit guidance
1. Every non-case interval must map to exactly one NPT code.
2. System downtime requires an outage reference where available.
3. Mis-coded NPT (e.g. downtime logged as break) is a reporting miss — correct
   it and note the correction.
4. NPT coding does not use NRR Column R; it is tracked in the capacity tool.
