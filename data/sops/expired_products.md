# Expired Products Policy

**Category code:** EXP-01
**NRR Column R descriptive name:** Expired products
**Knowledge link GUID:** GD2VHWRHSDNC8AJ7

## When this applies
A seller listing is removed or suppressed because the product is past its
expiry window, or the expiry metadata is missing or invalid. Common for
consumables, supplements, cosmetics, and perishable goods.

## Resolution steps
1. Confirm the removal reason code is EXP-01 (expired / expiry metadata).
2. Advise the seller to update the expiry date attribute on the listing.
3. Verify the corrected expiry window meets the minimum shelf-life threshold.
4. Reinstate the offer once the listing is compliant.

## NRR audit guidance
- Column R descriptive name must read exactly: "Expired products".
- Attach knowledge link GUID GD2VHWRHSDNC8AJ7.
- If reinstatement is pending seller action, mark as "Awaiting seller".
